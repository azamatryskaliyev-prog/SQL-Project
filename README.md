SQL Data Analysis Project

Описание проекта

В данном репозитории представлен итоговый учебный проект по анализу данных с использованием SQL.

Основные задачи

Написание SQL-запросов для анализа данных.

Фильтрация и сортировка данных.

Объединение таблиц с помощью JOIN.

Группировка и агрегирование данных.

Расчёт аналитических показателей.

Использование вложенных запросов.
